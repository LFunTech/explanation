# 题解工坊

给一道题，依据独立指定的目标年级与目标课标生成知识点讲解、详细解题、易错提醒、总结和变式题，交付可独立打开的 HTML、PPTX、逐页讲稿和语音。目标课标支持搜索多选、关联要求自动填充，也可点击“LLM 分析获取”根据题目、目标年级、学期与原题知识点匹配现有库中的课标原文；未匹配时不由模型补写；接口以 JSON 保存对应关系。未填写时使用原题知识点；原题年级只作为来源信息。

## 启动

支持 Python 3.11 / 3.12。前端是原生 ES modules，数学渲染资源已随仓库保存，无需 Node.js 构建，也不依赖 CDN。CI 使用团队镜像库已有的 Python 3.11，开发环境可继续使用 3.12。

```powershell
cd C:\Users\TMACY\lfun-github\explanation
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env  # 仅首次执行，不要覆盖已有配置
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 18765
```

Linux/macOS 对应使用 `.venv/bin/python`。知识图 PNG 需要中文字体：Windows 使用微软雅黑，macOS 使用苹方，Linux 安装 `fonts-noto-cjk`（Dockerfile 已包含）。打开 <http://127.0.0.1:18765>，接口文档为 <http://127.0.0.1:18765/docs>。

本机 `.env`、数据库与 `backups/` 快照、原始课标、生成课件和运行日志不提交 Git。`start.ps1` 可启动已安装依赖的 Windows 工作环境。运行时只允许一个进程使用同一数据目录，不要使用多个 workers 或多副本共享目录。

## 构建与部署

部署步骤见 [部署说明](docs/deployment.md)。仓库提供 Dockerfile、Woodpecker 验证/镜像构建/测试与生产发布流水线、Helm Chart 及单机 Compose。前端随 Python 服务打入同一镜像；运行配置由 Secret 注入，`/data` 持久化，固定单副本并使用 Recreate 更新。推送普通提交只验证，`test-vX.Y.Z` / `prod-vX.Y.Z` 标签才触发对应环境发布。

## 已实现

- 题目工作台：手动输入、选项、小题结构、参考答案/解析、图片上传、从 exam 公共题库选题。年级支持勾选多个，右侧按所选学科和任一已选年级随机展示 3 道题，未选年级时跨年级抽取；点击带入题库真实年级、完整题目及源 ID，使用千问生成。
- 千问生成：围绕本题的知识依据与应用 → 明确解题步骤 → 结构化配图 → 逐页语音与打包 → 预览；内容不满意时点击“重新生成”，按课件 ID 更新选中的记录。独立内容复核默认关闭，可用 `QWEN_INDEPENDENT_REVIEW=true` 启用。关闭时跳过独立复核与内容纠错循环，结果记录为“未独立复核”，仍保留打包、绘图和朗读所需的基本格式约束。参考 `knowledge-explanation/backend/book_runtime/courseware.py` 的上屏与讲解分工：画面突出结论、条件与关键推导，口语解释原理和读图方法，避免重复标题或扩写成通用课程。
- 原题排版：文字、公式与图片选项独立排列，保留真正的小题编号；兼容选项藏在单个小题或题干末尾的题库数据。工作台提供即时排版预览，课件、完整阅读区和 PPTX 使用同一原题结构；只在选项标签与附件顺序可以确认时绑定图片，原始题目保持不变。原题页依据实际渲染高度自动调整字号和间距，编号不拆行；确实放不下时按题干、选项和小题连续分页，保持公式完整。
- 内容与导出：不按简单/复杂题限制页数、字数、知识点数、步骤数或朗读时长；台词直接用于朗读，不再进入字符预算、强制精简或时长压缩循环。缺少步骤关联时整理为额外页面，不以覆盖检查阻断生成。原题、详细解析和已有文字完整保留；字号、2×2 布局和分页由排版处理。可选配图无法绘制时继续导出正文与 PPT，语音服务失败时仍完成 PPT 并使用设备朗读。
- 知识配图：数轴区间（开闭端点、方向）、一次/二次函数图、几何关系、简单电阻串并联及因果关系图。千问只给结构化参数，服务绘制 SVG/PNG，启用独立复核时把实际 PNG 与题目送入复核；不执行模型代码。图需对应当前知识，无读图价值不凑图；复杂科学图不在这些模板的适用范围内。原题附件只读保留，与生成示意图区分。
- 原生微应用：`/static/courseware-microapp.js` 提供 mount/update/unmount，直接挂载到宿主容器并使用 Shadow DOM 隔离；结果字段 `microapp_data_url` 提供受签名保护的数据。联调页 `/static/microapp-example.html`，接口文档含同源代理与生命周期示例。
- HTML：公式、分页、目录、逐页讲稿、语音、连续播放、16:9 缩放、完整解析与变式展开、原图与知识图放大、打印。字体、图片和已合成语音内嵌，下载后可离线打开。`manifest` 1.1 保留详细阅读内容及页数、实际语音时长、配图数量；ZIP 内同时提供 SVG/PNG，PPTX 使用相同图形的 PNG。
- 解题流程与播放：相关步骤合并成带箭头的流程图，节点包含具体动作、关键公式或结论；每个节点分别合成音频，按实际音频长度生成 `cues`，播放到哪一步就高亮哪一步。解题流程优先使用两列紧凑排列，四步采用 2×2；重复的流程示意图可点开查看。支持暂停/继续、翻页过渡、要点渐显与关闭动画，尊重设备减少动态效果设置。仍需滚动时，朗读会按实际语音时间点把当前步骤滚到课件可视区域；超高步骤及普通长页随朗读进度继续滚动，暂停时停止跟随，继续时保留进度，翻页后回到顶部。设备朗读按节点逐段触发，不用估计字数冒充音频对齐。
- 课标依据：生成使用请求中的 `target_grade` 与 `target_curriculum`，不再自动读取本地资源表或向量库补充课标。目标课标为空时仅回退原题知识点。本地课标用于生成前的知识点选择和“LLM 分析获取”，确认后的要求随请求提交；更新本地课标不会自动改变已提交的教学目标。显式配置的外部知识资源接口和题库变式仍可提供参考，`resource_ids` 只能引用本轮实际提供的资源；未关联资源时不标记为已匹配官方课标。
- PPTX：16:9、可编辑文字、Office Math 常用公式、逐页演讲者备注。复杂 LaTeX 的兼容性需在目标 PowerPoint/WPS 中复核；不承诺两种办公软件的渲染完全一致。
- 同一道题、同一年级和课标可以创建多份独立课件，每次创建返回新课件 ID 并重新调用模型；同一幂等键重试只重放原任务。按课件 ID 更新保持 ID 并递增版本，不影响同题其他课件。列表不再合并记录，支持服务端分页（每页 10/20/50 条）与全量年级、知识点、状态、关键词筛选。历史文件保留。
- 异步作业接口：逐题状态、部分成功、幂等请求、内容复用、不可变结果版本、失败题重试、检查点恢复。
- 上屏正文不再按 160/230 字限制阻断生成，较长内容交给排版；台词不设预算或字数限制。坐标图允许不在曲线上的动点或辅助点，超出画面的点自动扩展显示范围；直线优先使用明确的斜率与截距字段，并兼容明确线性标签对应的旧 `[k,b,0]` 参数顺序。
- 生成诊断：记录生成、语音与导出阶段；内容长度、页数和索引覆盖不会触发纠错循环；LLM 课件使用 SSE 流式接收，每 5 秒展示收到的字符数；180 秒是等待下一段数据的空闲超时，持续输出时总生成时长不限，TCP 连接超时独立为 15 秒。连接断开或缺少完成标记时丢弃本次残片重试，不把两次生成拼接。LLM 超时、连接中断及 HTTP 408/429/500/502/503/504 在当前阶段持续重试，间隔按 1、2、4、8、16、30 秒递增并保持最多 30 秒，不设次数上限；鉴权错误不重试，服务关闭可中断等待，重启后持久化任务继续执行。启用独立复核时会先保存候选，复核超时后重试可继续核对同一候选。关闭复核时直接进入语音与打包，不标记为复核通过。
- PPT 播放画布：桌面固定 16:9 并随窗口等比例缩放，讲稿和完整解析独立展开；确认属于 A–D 图片选项的题目，把字母与原图一起呈现。旧内容可用 `python -m scripts.restyle_package <package_id>` 生成新版排版，保留原版及已复核内容、音频，不重复调用模型。
- 回调通知：白名单、HMAC、持久化通知、指数退避、手动补发。回调失败不撤销课件。
- 存储：本地持久化，或上传到 S3/MinIO；全部文件上传成功后发布完成状态。
- 知识资源：本地 PostgreSQL 图谱与向量库、exam 只读导入、PDF/DOCX/TXT/MD 切分、千问 `text-embedding-v4` 1024 维向量、范围过滤和可追溯检索。
- 理科样例：数学因式分解、物理欧姆定律、化学质量守恒。样例模式只接受完全相同的原题和教学条件，不把样例结果用于任意新题。

## 千问与语音

```dotenv
DASHSCOPE_API_KEY=填写自己的密钥
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_MODEL=qwen-plus
QWEN_VISION_MODEL=qwen3-vl-plus
TTS_MODE=qwen
```

`TTS_MODE=qwen` 合成逐页 WAV，长稿按供应商长度限制切分后无损拼接，音频存入讲解包，不依赖会过期的供应商 URL。`browser` 使用设备语音，没有可下载的音频文件，设备没有中文语音时会明确提示。`none` 关闭语音。内置样例使用设备朗读，不产生模型费用。

调用方式依据 [千问 Chat Completions](https://help.aliyun.com/en/model-studio/qwen-api-via-openai-chat-completions)、[千问 TTS](https://help.aliyun.com/en/model-studio/qwen-tts-api) 和 [文本向量模型](https://help.aliyun.com/en/model-studio/text-embedding-v4)。密钥只由后端使用，不返回前端。未配置或真实生成失败时，不静默替换成样例。

结构化输出按模型能力选择：已支持的 Qwen3.7 Plus/Max/Flash、Qwen3.8 Max/Flash 文本请求使用严格 JSON Schema；现有 `qwen-plus` 和带图请求保留 JSON Object，再做本地校验。精简台词使用逐段 `maxLength` Schema，仍校验实际朗读合计与内容正确性。不会为启用严格模式自动更换模型。

## 知识库与题库

详见 [知识库说明](docs/knowledge-base.md)、[资源来源清单](docs/resources.md)。

远端 `exam` 连接一律以 `default_transaction_read_only=on` 建立，只读取公共教学资源及字典，不访问学生答卷或更改业务表。本地知识库使用独立 PostgreSQL 数据库。当前实现用 `REAL[]` 保存真实向量，以 SQL 计算精确余弦相似度，建立学科、区域、年级和知识点索引；不要求安装扩展。`compose.yaml` 提供可选的 pgvector PostgreSQL 实例，但当前检索仍为精确检索，没有启用 ANN/HNSW。

```powershell
# 同步知识图谱，保留源节点 ID、父子关系和语义关系
.\.venv\Scripts\python.exe -m scripts.sync_knowledge
# 可断点继续；已完成且模型/维度未变化的向量不会重复生成
.\.venv\Scripts\python.exe -m scripts.index_knowledge
```

也可在“知识资源”页面操作。索引任务通过数据库锁防止 CLI 与页面重复启动。首次导入只是建立图谱/文本记录，只有完成向量化的内容参与语义检索。扫描课标使用 `scripts.import_scanned_pdf` 逐页 OCR，命令和识别边界见知识库说明。

原题和变式题来自 `exam.public.question`。知识点、答案、解析、源 ID 一并保留。点选含图原题后，后端查询 `public.question_attachment`，按 `source_uri` 或公共 `file_metadata` 映射，从配置的 MinIO 桶只读下载原图并填入工作台。配置使用 `EXAM_MINIO_*`，凭证不发送给浏览器；题图以 data URL 随任务和讲解包保存，不依赖临时签名 URL。已有客户端提交带规范源 ID 的缺图题时也会自动补齐。附件读取失败明确提示并阻止缺图生成，可手动补充图片。当前含图题仍不作为变式候选。

题目年级读取 `exam.public.question.grade_code` 与 `exam.public.question_grade`，不关联租户字典；`G1`–`G12` 按源库年级代码显示。指定多个年级时按公共表匹配其中任一年级，选入题目时回填全部源年级；请求使用 `grades` 数组，旧 `grade` 字段继续兼容，任务保留原题年级；生成使用独立的 target_grade，HTML/PPT 页脚显示目标年级。指定年级时按公共表精确筛选，不用同学段题目冒充该年级；未标注时显示“年级未标注”，不默认九年级。提交和重新生成公共题库题目时也会重新读取源年级，避免旧客户端沿用错误值。源年级不隐式换算为上海学制或教材版本；知识图谱年级为空时仍按学段索引。高中缺少源图谱时可导入高中教材与课标，或使用千问生成，界面不伪造已存在的高中资源。

## 作业系统接入

完整契约见 [课件生成与播放对接文档](docs/integration.md)。作业系统调用 `POST /api/jobs`，保存响应顶层 `id`，查询或接收回调，再用 `question_id` 关联课件；推荐打开 `package_player_url`，使用 MinIO 时打开 `minio_package_player_url`。

```json
{
  "assignment_id": "homework-20261103-001",
  "title": "九年级数学练习",
  "questions": [{
    "question_id": "q-001",
    "stem": "解方程：$x^2-5x+6=0$。",
    "subject": "数学",
    "grade": "九年级",
    "target_grade": "九年级",
    "target_curriculum": [{"knowledge_point":"一元二次方程","curriculum_requirements":["理解方程解的含义","能用因式分解法解方程"]}],
    "region": "上海",
    "knowledge_points": ["一元二次方程", "因式分解"],
    "question_type": "解答题",
    "difficulty": "中等"
  }],
  "options": {"mode": "qwen", "depth": "standard", "variant_count": 2, "voice": true, "force": false}
}
```

本地服务默认只监听 `127.0.0.1`。部署到局域网或公网时设置 `API_KEY`、反向代理 HTTPS 和 `PUBLIC_BASE_URL`；应用是面向一个受信作业系统的服务实例，没有实现学校/租户级身份与数据隔离。浏览器工作台使用 HttpOnly 会话；作业调用使用 `X-API-Key`。结果链接可带 7 天签名，过期后重新查询任务取得新链接。

预览外壳默认铺满浏览器视口，不需要进入浏览器全屏；课件在固定的 `80rem × 45rem`（16:9）画布内排版，再整体缩放到可用区域。字号由每页内容量决定：短题干、单步公式和简短知识点适当放大，长内容按完整段落分页。窗口尺寸变化或目录开合只改变整体缩放比例，保持字号比例、换行、图文位置和分页一致；正文和公式不出现滚动条，不通过裁切丢弃内容。桌面目录可收起，窄屏使用带遮罩的目录抽屉，选页后自动收起并保留当前页定位。

课件包同时提供 `player.html` 和纯内容入口。`player.html` 自带目录、翻页、讲稿、完整解析、朗读和打印，内嵌图文、字体及已合成音频；MinIO 与 ZIP 都包含它，打开即可播放，不需要接入 SDK。`package_player_url` 指向服务目录中的该文件，`minio_package_player_url` 校验权限后跳转到 MinIO 对象。完整播放文件可能较大，需要快速首屏时继续使用轻量在线入口。

`index.html` 保留纯课件内容，不带外壳；`html_url` 指向它，适合自定义宿主。`player_url` 仍提供服务端在线外壳。动画默认开启，页脚显示年级与学科，区域只作为教学条件保存。已有课件可用 `python scripts/add_package_player.py --publish` 补入包内播放入口，无需重新调用模型或合成语音。

MinIO 引用示例：上传完成后打开结果中的 `minio_player_url`，其播放器直接嵌入 MinIO 上的课件文件。服务端签发 1 小时的读取链接，刷新示例页即可更新；`S3_PUBLIC_ENDPOINT_URL` 可指定浏览器访问域名，留空时使用上传端点。

在线预览使用 `online.html`（`content_url`），首屏只加载图文，语音在点击播放后按页读取；离线 `index.html` 仍内嵌语音。MinIO 示例连续 12 秒未就绪时使用相同课件的本地副本，并显示“本地副本”。对外引用私有对象存储时，宿主通过 `init` 的 `audio` 参数传入 `page_id → 已签名音频 URL`。

自定义页面可使用 `/static/courseware-sdk.js`：`new CoursewareSDK.Player(iframe)` 后，通过 `load(config)` 加载、`on('state', ...)` 更新外壳，调用 `next()`、`previous()`、`play()`、`goTo(index)` 控制课件。生成结果的 `embed_config_url` 提供配置；需要 MinIO 时追加 `source=minio`。可运行示例位于 `/static/embed-example.html?config=` 加 URL 编码后的配置地址。动画默认开启，外壳无需增加动画开关；接入代码见 [集成说明](docs/integration.md)。

原图可以通过每页的 `source_image_index` 和 `source_image_caption` 直接引用，不需要重新画一张示意图。低年级优先使用原题实物、指认和逐个数，不以抽象数轴或字母通式代替；插图和语言深度使用独立指定的目标年级。题库取题匹配任一所选年级，连接采用只读事务、复用与短暂故障重试。

选题服务会缓存最近 24 小时成功读取的真实公共题目。连接异常或等待超过 4 秒时，有匹配年级的缓存则先返回并标记 `cached: true`，后台继续读取；页面会明确说明使用了最近读取的题目。手动多选年级不会被后续选题操作覆盖。

嵌入时使用 iframe（需要朗读时添加 `allow="autoplay"`），通过 `postMessage` 控制内容：

```js
lessonFrame.contentWindow.postMessage({
  channel: 'courseware', version: 1, type: 'command',
  command: 'goTo', value: 0 // 从 0 开始的课件页索引
}, '*');
```

支持 `init`、`next`、`previous`、`goTo`、`seek`（自适应分页后的页码）、`play`（播放/暂停切换）、`stop`、`setAutoPlay`、`setMotion`、`print`、`getState`。内容向父窗口发送 `ready`、`state`、`error` 事件，使用相同的 `channel` 和 `version`，数据位于 `payload`；引用方应校验 `event.source === lessonFrame.contentWindow`。`ready` 包含标题、目录、讲解和阅读区资料；`state` 包含当前课件索引、分页位置和播放状态。同源直接访问时也可使用 `window.CoursewareContent` 接口。

对外单题创建使用 `POST /api/courseware`，传公共题库 `question_id`、`target_grade`、可选的 `target_semester` 和 `target_curriculum`，后端读取完整原题与附件。目标学期可选 `全学期`（默认）、`上半学期`、`下半学期`；同题不同年级、学期和课标分别保存，可同时生成。目标课标数组每项包含 `knowledge_point`、单个 `grade` 和 `curriculum_requirements` 文字数组，要求用于约束该知识点的讲解深度与解题方法。改动目标会产生新的内容指纹，旧目标的课件不会被误复用。新课件的 MinIO 目录为 `{S3_PREFIX}/{目标年级}/{目标学期}/{题目ID摘要}/{package_id}/`；旧目录继续可读。创建页保持现有样式作为本地测试入口，公共原题调用上述接口，手工输入仍可通过完整题目接口测试。

目标课标每项用 `grade` 对应唯一年级，`grade_source` 区分题库、LLM、手动与待确定。知识点可多选，同名知识点不同年级的要求独立保存；切换年级会清空原要求，LLM 分析按对应年级重新匹配库内课标。旧单元素 `grades` 自动兼容，旧多元素数组需重新确定年级，不复制共用要求。

播放器放大配图使用整个宿主视口，支持 Esc 关闭。自建 SDK 外壳可在 load 配置中设置 `figureHost:true` 并监听 `figure` 事件（`src/alt/caption`）；未设置时纯内容页在自身视口查看图片。
