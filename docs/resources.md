# 上海教材与课标来源清单

核实日期：2026-11-03。教材版本先按上海当年度教学用书目录核对，不能以网络上标注“沪教版”的文件名作为版本依据。

| 资源 | 可靠入口 | 用法与当前边界 |
|---|---|---|
| 上海数字教材 | [市教委官方说明](https://edu.sh.gov.cn/xxgk2_zhzw_jyta_02/20231024/4fc69936201a44c88bd29352687a5d53.html)；[标准版平台](https://www.sh-genius.cn/)；[人教版平台](https://shszjc.mypep.cn/) | 使用上海基础教育统一身份登录；通过正式提供方取得可用于索引的资料，保留版本和页码。尚未导入整套教材。 |
| 当年度教材目录 | [2026 年秋季中小学教学用书目录](https://edu.sh.gov.cn/xxgk2_zdgz_jcjy_04/20260810/339e915d906842caaf98736d562df96a.html) | 确认学制、学科、年级与使用版本。 |
| 义务教育课标 | [教育部 2022 年版原文](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)；[上海市教委转发及附件](https://edu.sh.gov.cn/mbjy_fgwx_qt/20220720/02b90de93ebd49099e43063f7a6e2630.html) | 可按学科下载正式附件。数学采用页面明确的 2022-05-09 修正版。 |
| 普通高中课标 | [教育部 2017 年版 2020 年修订通知](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html) | 与义务教育分开索引，按科目和版本管理。 |
| 上海课件与配套资源 | [上海智慧教育平台](https://www.sh.smartedu.cn/teachingMaterial?type=3) | 核对资源对应教材与学期；是否可导出及纳入服务按提供方条件办理。 |
| 题目与知识图谱 | 用户授权的 exam 公共资源库 | 已实现只读导入和实时查询，不复制学生数据。 |

首轮建议由资源侧交付：上海数学、物理、化学当前所用教材的目录/版本；可索引正文或明确授权的电子文件；官方课标 PDF；章节与知识点 ID 映射；题目图片与附件的正式访问方式；语音与对象存储运行凭证。

课标限定教学目标与范围，教材提供解释和例题，题库提供原题与变式，图谱提供关联和先修关系。四类资源分别保留来源，不把知识点名称自动扩写为“教材原文”。

本机首轮已导入 [义务教育物理课标（2022 年版，上海教委附件）](https://edu.sh.gov.cn/cmsres/a6/a6f21f6cc8e249bc8e82fc8f3bb2cdc5/3f99f5955398f941cb6bdf6089e2f654.pdf)：71 页扫描件，通过千问视觉 OCR 得到正文并完成向量化。原始文件与页级缓存可追溯，识别文字标记为机器提取，公式和表格仍需核对。数学课标修正版已下载，暂未 OCR 入库；上海整套中小学教材尚待正式提供可索引资料。
