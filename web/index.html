提交生成请求

接口约定
POST /api/courseware
传题目 ID、目标年级、可选学期和目标课标。Idempotency-Key 防止重复创建。
GET /api/jobs/{job_id}
返回逐题状态、错误原因和下载链接。
GET /api/assignments/{id}
按作业查看历次生成任务。
POST /api/jobs/{id}/retry
仅重试失败题目，复用已通过复核的检查点。
复用与版本
每次创建返回独立课件 ID；按课件 ID 更新时保留 ID 并生成新版本，旧链接保留。批量作业仍支持内容复用。
完成通知
回调白名单与 HMAC 签名，失败最多重试 5 次。事件 ID 用于接收侧去重。
生产接入需配置 API_KEY、回调地址与存储。回调失败不会影响已完成课件的查看。
